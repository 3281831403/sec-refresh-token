刷新令牌被盗用之后，对方一直能续期，而真正用户完全没收到任何告警：轮换后旧令牌不标记已用，攻击者可以无限次重放旧令牌；复用检测只拒绝本次请求，不吊销整族，攻击者换一个令牌继续续期；家族标识直接用用户标识，同一用户的多个客户端共用家族，一处泄露牵连所有终端；客户端绑定用前缀比较，web 与 web-mobile 被判成同一客户端；绝对有效期缺失，只要一直续期就能永久使用；空闲有效期不随使用更新，长期不用和频繁使用被同样对待；吊销只删当前令牌，家族内其他令牌仍然有效；策略校验不检查是否启用复用检测，关掉复用检测也能通过；轮换时新令牌复用旧令牌的熵，令牌值可预测；批量处理复用家族状态，后一个请求命中前一个请求的家族。token/refresh.py 是核心，tests/unit/test_refresh.py 15个红。要修的是：按上面的顺序把 10 个缺陷逐个修掉。

## 契约与约束

- 令牌值为 64 个小写十六进制字符；家族标识为 32 个小写十六进制字符；熵源至少 32 字节。
- 时间戳统一使用 Unix epoch 毫秒，策略中的有效期使用秒，实现必须显式做单位归一化；时间容差为 0，年龄达到上限即失效。
- 绝对有效期锚定家族创建时间，空闲有效期锚定最近一次成功轮换时间；轮换只能刷新空闲锚点，不能刷新绝对锚点。
- 家族标识由用户标识与客户端标识共同决定：同一用户的多个客户端必须是不同家族。
- 任一复用证据都必须吊销整个家族，家族内全部令牌同时失效，而不只是本次出示的令牌。
- 只使用标准库（hashlib、hmac、secrets、time）和 pytest；离线运行，不联网、不安装依赖。
- 不使用 random、os.urandom、time.time() 一类隐式随机或时钟；熵源、当前时间和存储状态都由调用方显式传入，相同输入必须得到相同输出。
- store 是普通字典：`secret`（服务端密钥，至少 32 字节）、`seq`（每签发一个令牌加一）、`families`（按家族标识索引）、`tokens`（按令牌值索引）。家族记录含 `family_id`、`user`、`client`、`created_at`、`revoked_at`、`tokens`；令牌记录含 `token`、`family_id`、`user`、`client`、`created_at`、`issued_at`、`last_used_at`、`used_at`、`previous`。记录是纯字典、没有反向引用，因此可以用 copy.deepcopy 复制存储，副本在相同输入下必须得到相同结果。
- 修复范围只允许 `token/refresh.py`，8 个函数逐一实现；`tests` 目录为固定验收测试，不得修改、删除、跳过、xfail、改写断言或缩减测试数量。
- 包名 `token` 与标准库 `token` 同名，`token/__init__.py` 与 `conftest.py` 只负责导入兼容，同样不属于修复范围，不要改动。
